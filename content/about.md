# 关于这个网站

这里是 **壹句**——一个记录折腾过程的小站。

## 这是什么

内容以「折腾小记」为主：修网站、排 bug、调样式这类事的完整记录。每篇都尽量写清楚**现象 → 排查弯路 → 根因 → 修法 → 经验**，因为踩坑的过程往往比答案本身更有价值。

## 怎么搭的

- **框架**：[Hugo](https://gohugo.io/) + [PaperMod](https://github.com/adityatelange/hugo-PaperMod) 主题
- **写作**：[思源笔记](https://github.com/siyuan-note/siyuan) 里写，脚本同步成 Markdown
- **托管**：GitHub Pages，推送即自动部署
- **滚动**：首页是信息流式加载，往下滑自动翻页，不用点分页

## 为什么叫「壹句」

话不在多，一句到位。这里的文章也尽量保持这个调性——短、准、有用。
