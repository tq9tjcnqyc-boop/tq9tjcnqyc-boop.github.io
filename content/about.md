# 关于这个网站

专利档案库——专利文件存档与检索站。

## 这是什么

本站用于存档专利文档（实用新型、发明专利等），按标准专利文书格式整理：说明书摘要、摘要附图、权利要求书、说明书（技术领域、背景技术、实用新型内容、附图说明、具体实施方式）、说明书附图。

每篇专利都保持原始文书的层级结构，方便检索、翻阅和引用。

## 内容格式

每篇存档遵循专利文书的标准章节：

- **说明书摘要**：技术方案概要 + 摘要附图
- **权利要求书**：逐项权利要求
- **说明书**：技术领域 → 背景技术 → 实用新型内容（含有益效果）→ 附图说明 → 具体实施方式（含工作原理）
- **说明书附图**：与说明书同一层级

## 怎么搭的

- **框架**：[Hugo](https://gohugo.io/) + [PaperMod](https://github.com/adityatelange/hugo-PaperMod) 主题
- **来源**：专利文档（Word/PDF）经转换整理为 Markdown
- **图片**：独立图床托管，不占站点仓库
- **托管**：GitHub Pages，推送即自动部署
