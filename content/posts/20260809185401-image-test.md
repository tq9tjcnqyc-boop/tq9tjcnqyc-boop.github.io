# 折腾小记：给网站加上图片

网站建好到现在，文章一直只有文字。今天试试图片能不能正常走完「思源 → sync → GitHub Pages」整条管线，顺便看看 PaperMod 主题对图片的排版效果。

## 图片是怎么走通管线的

sync-site 里有个 `fix_asset`​ 函数：思源笔记里的图片引用是 `assets/xxx`​ 相对路径，同步时会把这个文件从思源的数据目录复制到站点的 `static/assets/`​，同时把 markdown 里的引用改写成 `/assets/xxx`​ 绝对路径。这样图片就跟文章一起进了 Hugo 构建产物，部署后由 GitHub Pages 托管。

## 小结

带图片的文章发布流程和纯文字完全一样：图片丢进思源 assets 目录 → markdown 里写 `assets/文件名`​ → createDocWithMd 创建文档 → sync-site 同步。唯一多出来的步骤是图片要先进思源的 assets 目录，sync 才会认得并复制。
