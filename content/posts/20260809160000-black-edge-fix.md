# 折腾小记：Hugo + PaperMod 网站滚动到底的「黑边」

前两天在手机上翻自己的小站，滚到页面底部时，底下总会露出一条刺眼的黑边。明明页面是白色主题，为什么橡皮筋拉出来的地方是黑的？这个问题折腾了好几个小时，试了四五版方案才搞明白，值得记下来。

---

### 现象

- 桌面浏览器（macOS 深色模式）：滚动到底继续拉，露出**纯黑**色带。
- 手机 Safari（浅色主题）：页面是白的，但底部工具栏和橡皮筋区域是**深灰色**（rgb 47,46,52 左右）。
- 切换成白色主题后，黑边依然存在，颜色根本不跟随主题。

一开始以为是缓存问题，排查半天发现**根本不是缓存**——是两层根因叠在一起。

---

### 根因一：html 元素没有背景色（桌面端）

PaperMod 主题只给 `body`​ 设置了 `background: var(--theme)`​，`html`​ 元素是透明的。

macOS 橡皮筋滚动（overscroll）露出的区域，填的是 **html 元素的背景**。html 透明 → 露出浏览器 canvas 的默认色：深色模式下就是纯黑。

**修法**（`assets/css/extended/custom.css`​）：

```css
html {
  background: var(--theme);
}
```

这样橡皮筋露出的条带就跟页面主题色一致了。

---

### 根因二：theme-color 被写死（移动端）

桌面修好之后，手机 Safari 上还是黑边。这次更隐蔽——PaperMod 的 `head.html`​ 里有一行：

```html
<meta name="theme-color" content="#2e2e33">
```

​`theme-color`​ 是告诉手机浏览器「工具栏 / 橡皮筋区域用什么颜色」的 meta 标签。PaperMod 把它**写死成深灰 #2e2e33**，不跟随网页主题切换。所以手机 Safari 的底部永远是深灰，切白主题也没用。

**修法**（两处）：

1. ​`hugo.toml`​ 里把默认值改成白色：

```toml
[params.assets]
  theme_color = '#ffffff'
```

2. 利用 PaperMod 的 `extend_head.html`​ 钩子注入 JS，让 theme-color 跟随主题动态切换：

```html
<script>
    (function () {
        var meta = document.querySelector('meta[name="theme-color"]');
        if (!meta) return;
        function syncThemeColor() {
            var theme = document.documentElement.dataset.theme;
            meta.content = (theme === 'dark') ? '#1d1e20' : '#ffffff';
        }
        syncThemeColor();
        new MutationObserver(syncThemeColor).observe(
            document.documentElement,
            { attributes: true, attributeFilter: ['data-theme'] }
        );
    })();
</script>
```

​`MutationObserver`​ 监听 `html`​ 的 `data-theme`​ 属性，用户点主题切换按钮时实时同步 toolbar 颜色。

---

### 后续：把颜色统一出层次感

黑边解决后，又发现浅色主题下主页背景和文章页背景不一致（主页浅灰、文章纯白），深色模式下却是统一的。最后决定：

- 浅色模式：主页背景 = 纯白，文章卡片 = 浅灰（对调了 PaperMod 默认的两个变量值）
- 深色模式：保持原样（本来就统一）
- 手机工具栏颜色也跟随主页背景

```css
/* 浅色：主页列表背景用卡片原色（白），卡片用列表原色（浅灰） */
html:not([data-theme="dark"]) .list {
  background: var(--entry);
}
html:not([data-theme="dark"]) .post-entry {
  background: var(--code-bg);
}
```

---

### 踩坑记录

1. **custom.css 不能写中文注释**。hugo minify 时，含中文的 `/* */`​ 会让整个文件被丢弃，页面字体、样式静默消失。排查时一度以为 CSS 没生效，其实是被 minify 吃掉了。 2. **桌面端和移动端的橡皮筋颜色机制不同**。桌面看 html 背景，手机 Safari 看 theme-color。只修一个，另一个必然露馅。 3. **验证要抓真实计算值**。用 headless Chrome 的 CDP 接口 `getComputedStyle(document.documentElement).backgroundColor`​，改前是 `rgba(0,0,0,0)`​，改后才是主题色，一眼看出有没有生效。 4. **GitHub Pages 部署有延迟**。每次 push 后等 Actions 构建 + CDN 生效，约 1-2 分钟，验证线上时别急着下结论。

---

### 小结

「黑边」不是缓存问题，是两层根因叠加：html 无背景 + theme-color 写死。两处修法都不复杂，但**每一层根因都藏在不同设备的渲染机制里**——桌面看 html，手机看 meta。调这类问题，别凭感觉猜，直接用 headless 浏览器读计算样式，一抓一个准。
