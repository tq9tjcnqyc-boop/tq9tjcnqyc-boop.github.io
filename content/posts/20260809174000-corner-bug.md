接上一篇「黑边」的坑，这次是代码块的边框问题：手机浅色模式下，代码块看起来有两层边框——外层是圆角的，内层是直角的，圆角弧线处总有一条直角边框「伸」出来。

这个问题修了三轮才真正解决，前两轮都是白忙活。记下来，下次少走弯路。

## 弯路一：以为是 CSS 边框叠加

第一反应是「边框加多了」。检查样式，发现浅色模式下 `.highlight` 和内部的 `pre` / `code` 曾经都加过 `1px` 边框，只有外层有圆角，内层是直角——正好符合「外圆内直」的现象。

于是把边框收敛到只剩外层一条，内层全部 `border: 0 !important`。本地、线上都验证过只有一条边框，但用户手机上还是老样子。

## 弯路二：以为是缓存

第二轮上了「JS 铁闸」——页面加载后用 JS 给内层元素写 inline 样式，强制去边框。inline 样式优先级最高，理论上任何缓存的旧 CSS 都压不住。结果还是不行。

## 转机：用户一句话点醒

用户说：「圆角边缘还是有直角边框伸出来。」

这句话比「两层边框」精确得多。重新看渲染结构才发现：真正的问题根本不是边框，是**背景**。

外层 `.highlight` 是圆角（8px），但内层 `pre` 的背景色是**直角**的——它没有圆角。直角背景从外层圆角弧线处伸出来，视觉上就像「一条直角边框戳出圆角」。放大截图后尤其明显。

## 真正的修法

```css
/* 内层背景透明，圆角跟随外层——直角背景不再从圆角伸出 */
.highlight pre, .highlight .chroma, .highlight pre code {
  border: 0 !important;
  background-color: transparent !important;
  border-radius: var(--radius);
}
```

内层不再画背景，底色统一由外层圆角框提供；内层圆角也跟外层一致，双保险。JS 铁闸同步加了背景透明。这次一次性解决。

## 教训

1. <strong>「看起来像边框」的不一定是边框</strong>——可能是背景色块的边缘。查样式问题时，border 和 background 都要查。 2. **用户的原话是最精确的 bug 描述**。「圆角边缘有直角边框伸出来」比「两层边框」信息量大得多，早点顺着这个线索查，能少绕两轮。 3. **放大截图会放大一切**——包括 1px 边框和 8px 圆角。用放大截图判断「边框粗细」不可靠，要看结构（有几条线、圆角弧线在哪），别比尺寸。 4. **线上验证要等部署 + 确认缓存**，但「缓存」不应该是第一结论。先把代码层面可能的来源全部堵死（JS inline 样式兜底），再谈缓存。
